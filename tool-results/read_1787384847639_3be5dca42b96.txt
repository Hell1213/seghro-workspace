    24→## V14 Session — Theme Blink Fix + Cursor Fix + Production Launch Audit
    25→
    26→### 1. Theme Toggle Blink Fix (Root Cause + Fix)
    27→**Root cause:** Three separate issues caused visible blink during theme switching:
    28→- `AnimatePresence mode="wait"` with scale-0→1 animation caused the toggle icon to disappear then reappear
    29→- `transition-all` on Button component caused ALL CSS properties (including colors) to animate through intermediate states during theme class change
    30→- Same `transition-all` pattern on navbar and other elements amplified the flash
    31→
    32→**Fix applied (3-layer):**
    33→1. **Navbar theme toggle** — Replaced `AnimatePresence` with pure CSS crossfade: both Sun/Moon icons rendered simultaneously, one hidden via `opacity-0 scale-50 pointer-events-none`, toggled via `transition-all duration-200`. Zero unmount/remount.
    34→2. **Button component** — Changed base class from `transition-all` to `transition-[color,background-color,border-color,box-shadow,transform]` to exclude irrelevant properties from transitioning.
    35→3. **Global theme-switching class** — Added `handleThemeToggle()` that: (a) adds `.theme-switching` class to `<html>`, (b) forces reflow, (c) changes theme, (d) removes class on next animation frame. CSS rule `.theme-switching, .theme-switching *, .theme-switching *::before, .theme-switching *::after { transition: none !important; }` ensures zero visual transition during class swap. After 2 frames, transitions resume for normal hover/click effects.
    36→
    37→### 2. Global Cursor Pointer Fix
    38→Added global CSS rule in `@layer base` targeting all interactive elements:
    39→`a, button, [role="button"], [role="tab"], [role="link"], [role="option"], [role="switch"], [role="checkbox"], [role="radio"], [role="menuitem"], summary, select, input[type="checkbox"], input[type="radio"], input[type="range"], input[type="color"], input[type="file"], label[for], [onclick] { cursor: pointer; }`
    40→This ensures immediate pointer cursor on hover for every clickable element across the entire app.
